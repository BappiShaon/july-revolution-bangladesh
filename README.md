# July 2024 Bangladesh Revolution - Academic Literature Dataset

📚 Comprehensive open-source database of academic research on Bangladesh's July 2024 Revolution

## 📊 Dataset Overview

- 104 Academic Articles (peer-reviewed journals, books, dissertations)
- 82 PDF Files (full-text articles)
- Multiple Categories: Health, Politics, Media, Human Rights, Education, Social Movement
- CC0 License - Free to use, no credit required!

## 📥 How to Contribute

Found an article about July 2024 Revolution? Help us grow the dataset!

### Option 1: Create GitHub Issue (Easiest)

1. Click Issues tab
2. Click New Issue
3. Add:
   - Article Title
   - Authors
   - Publication Year
   - Journal Name
   - DOI/URL
   - Category (Politics/Health/Media/Law/Education/Social Movement/Other)
   - PDF file (if available)

### Option 2: Direct Email

Send article details to: syful.au.bd@gmail.com

## ✅ Verification Process

1. We check if article is about July 2024 Revolution
2. Verify no duplicates
3. Add to dataset with proper categorization
4. Credit contributors
